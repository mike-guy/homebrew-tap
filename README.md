# mike-guy/homebrew-tap

[Homebrew](https://brew.sh/) packages for tools by [mike-guy](https://github.com/mike-guy).

## Install

```sh
brew install mike-guy/tap/azskufinder
```

That adds this tap and installs the package in one step. To add the tap on its
own, run `brew tap mike-guy/tap`.

## Packages

| Package | Description |
|---|---|
| [azskufinder](https://github.com/mike-guy/azskufinder) | Find the Azure VM sizes you can actually deploy |

## Updates and issues

The casks in `Casks/` are written automatically by each project's release
workflow, so please don't edit them by hand. `brew upgrade` picks up new
releases.

To report a problem with a package, please open an issue in that project's
repository, for example
[azskufinder's issues](https://github.com/mike-guy/azskufinder/issues).
